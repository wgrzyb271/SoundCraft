# SoundCraft
Multi-agent AI system for editing, separation of tracks and sound synthesis controlled by natural language. It combines the orchestration of agents in LangGraph with precision audio models and digital signal processing, offering automatic quality control and mastering.

Setup instructions, a local no-GPU demo, and WCSS commands are available in
[llm_agent/README.md](llm_agent/README.md).
